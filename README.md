# WeXL Laboratory Pvt. Ltd. — Official Website

> Premier NABL ISO/IEC 17025:2017 Accredited & ISO 9001:2015 Certified Materials, Metal, Polymer & Automobile Testing Laboratory in IMT Manesar, Gurugram. Founded by Dr. Amit Bishnoi.

## Features
- **Modern React & Vite SPA**: Fast, lightweight single-page application with responsive desktop & mobile navigation.
- **Interactive Three.js 3D Engine**: 3D WeXL insignia medallion with dynamic tangent-space normal mapping, specular reflection, dual metrology orbital rings, and orbiting element atoms.
- **Accredited Domains**: Metals & Chemical Spectroscopy (OES/ICP), Mechanical & Tensile (1000 kN UTM), Plastics & Polymers (FTIR / MFI), Salt Spray (NSS/CASS 450 L), RoHS / ELV Compliance, and Metallography.
- **Equipment Showcase**: Detailed catalog of high-resolution laboratory instrumentation.
- **Traceable Calibration**: In partnership with M/s AVI Calibration Services LLP.
- **Instant Turnaround & Cost Calculator**: Parametric estimation tool for sample testing protocols.
- **Verified Client Roster**: Real partner logos extracted from official company credentials (Bajaj, JTEKT, Allied, GAIL, Forza Medi, and 35+ industry leaders).
- **Digital Report Verification**: QR code and ULR certificate verification with print-ready audit cards.
- **Direct RFQ Desk**: Interactive sample drop-off and quotation requests with confetti animations.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
```

## Tech Stack
- React 18
- Vite
- Tailwind CSS v4
- Three.js
- GSAP (GreenSock)
- Lucide React
- Canvas Confetti
